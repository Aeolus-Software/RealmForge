The main goals of this project include:

\begin{itemize}

    \item Develop a complete playable roguelite game with a gameplay loop that includes a central hub, enemy encounters, player progression, and the ability to begin a new run after failure.

    \item Allow players to make strategic decisions during encounters through the use of resources, available actions, and upgrades to the central hub. 

    \item Implement variations in game features across different builds to create different player experiences for usability testing. 

    \item Use usability testing on selected game variations to analyze how different versions affect the player experience.

    \item Use the results from the usability study to determine which variations improve the overall player experience in a roguelite game.

\end{itemize}
