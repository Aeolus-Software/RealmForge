The main goals of this project include:

\begin{enumerate}

    \item Develop a complete playable roguelite game with a gameplay loop that includes enemy encounters, player progression, and the ability to begin a new run after failure.

    \item Allow players to make decisions that influence their experience within the game, such as choices involving attacks, encounters, or progression.

    \item Implement variations in game features to create different experiences for players across different versions of the game.

    \item Use usability testing on selected game variations to analyze how different versions affect the player experience.

    \item Use the results from the usability study to determine which variations improve the overall player experience in a roguelite game.

\end{enumerate}
