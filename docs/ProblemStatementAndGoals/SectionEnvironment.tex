\textbf{Hardware Environment}:
The project will be able to run on users' laptops or PCs. The user will interact with the game using either a keyboard + mouse or a standard game controller (XBOX, PlayStation, etc.).
\\
\\
\textbf{Software Environment}:
The project may be supported on multiple operating systems, such as Windows, MacOS, and various Linux distributions. The environment is composed of the core gameplay loop, which includes intractable characters/objects and various UI elements. The usability data may be collected online through a form.
