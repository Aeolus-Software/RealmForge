\section{MIS of Game World (M7)} \label{M7-GameWorld}

\subsection{Module}
The game world module handles game state and player location changes. It communicates with the respective Game World UI for player input.  

\subsection{Uses}
\begin{itemize}
    \item Uses the Godot Singleton class
    \item Godot World Interface Module
\end{itemize}

\subsection{Syntax}
\subsubsection{State Variables}
\begin{itemize}
    \item state: GameState - The state of the game. This is important so that the game knows what sequence or step it is currently on. The game should be follow a strict flowchart guideline (See SRS Figure: RealmForge System Flowchart \cite{SRS}). 
    \item \verb|current_location|: String - The designated current area shown and process.
\end{itemize}


\subsubsection{Environment Variables}



\subsubsection{Assumptions}
\begin{itemize}
    \item This module maintains the state of the overall game.   
    \item No other module should be able to change the state of the game.
    \item The other modules may signal to the game world module for a game state change.
    \item One instance of Game World Module
\end{itemize}
