\section{MIS of Game World (M7)} \label{M7-GameWorld}

\subsection{Module}
The main module that handles game states, transitioning between game states, communication with all other sub modules, helping with UI signals and rendering the whole game. Is a Godot Singleton and has leaves such as the player, enemy, and combat module.


\subsection{Uses}
\begin{itemize}
    \item Uses the Godot Singleton class
    \item Godot World Interface Module
\end{itemize}

\subsubsection{Exported Constants}
