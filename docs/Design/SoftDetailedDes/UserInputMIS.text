\subsection{Module}

This module handles external input from the user, via a physical input device 
(a 
controller, or a keyboard and mouse combination). It is implemented by the 
Godot Engine 
(through its provided input functionality spread throughtout the engine) for 
use by the RealmForge software. The details provided in this MIS description 
are provided by the Godot Engine Documentation \cite{GodotDocs}. The full set 
of access programs, exported constants, and other functionalities the Godot 
Engine provides for input will not be enumerated (as it is quite lengthy); 
details relevant to the RealmForge software's development are included.

\subsection{Uses}

\begin{enumerate}
	\item Simple Directmedia Layer 3 (SDL) Library (used to manage controller 
	input)
	\item Win32 API (native Windows API, to manage keyboard and mouse input)
\end{enumerate}

\subsubsection{Exported Access Programs}

The Godot Engine does not provide functionality for exceptions, in favour of 
methods returning error values, or raising error warnings/flags (to avoid 
crashing or halting the software, so that errors can be handled and the game 
can continue to execute). As an alternative, exported access programs outlined 
for each module's specification in this document will describe the error 
logging or returned error values that are provided following an error in an 
access program.\\

\subsection{Semantics}

\subsubsection{State Variables}

All internal variables related to the current state of the user's input, and 
its connection to the user's machine. These variables are used internally by 
the Godot Engine and hidden to RealmForge's implemented software.

\subsubsection{Environment Variables}

For a controller used as an input device:
\begin{itemize}
	\item states of controller buttons
	\item joystick positions
	\item trigger positions
\end{itemize}

\noindent For a keyboard and mouse combination used as input devices:
\begin{itemize}
\item currently pressed keys
\item mouse cursor position
\item states of mouse buttons
\end{itemize}

\subsubsection{Assumptions}

\begin{itemize}
	\item Input variables and data provided by the Godot Engine's Input, 
	InputEvent, and InputMap classes are valid, when a valid physical input 
	device is correctly connected to the user's machine.
\end{itemize}
