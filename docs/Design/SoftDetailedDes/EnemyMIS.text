\subsection{Module}

This module abstracts the attributes of each instantiated enemy 
character in the RealmForge game, and provides these details to other modules 
as needed.

\subsection{Uses}

\begin{enumerate}
	\item Godot Engine (functions, nodes, and signals provided by the engine 
	automatically)
\end{enumerate}

\subsection{Semantics}

\subsubsection{State Variables}

\begin{itemize}
	\item health : int
	\item available\_actions : array of custom resources (a resource will be 
	defined to store data related to each possible action the enemy character 
	can take in combat, such as its damage, speed, or other qualities)
\end{itemize}

\subsubsection{Environment Variables}

\begin{itemize}
	\item the enemy character's visual depiction (two-dimensional sprite) 
	displayed by the user's display device
	\item the enemy character's visual animations displayed by the user's 
	display device
\end{itemize}
