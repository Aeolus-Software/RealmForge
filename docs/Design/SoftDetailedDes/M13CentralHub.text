\section{MIS of Central Hub M13} \label{M13-CentralHub}

\subsection{Module}
This module will store and update information concerning the player's temporary and permanent upgrades towards their Central Hub as well as having an algorithm to determine which upgrades to allow for unlock at certain stages. With the stored upgrade information, this module will calculate resource generation rates and game modifiers to be accessed by other modules.

\subsection{Semantics}
\subsubsection{State Variables}
\begin{itemize}
    \item \verb|currency: int| - Tracks the player's current available resource/currency count for purchasing upgrades.
    \item \verb|permanent_upgrades: Array[Upgrade]| - Stores the collection of permanent hub upgrades unlocked by the player.
    \item \verb|temporary_upgrades: Array[Upgrade]| - Stores the collection of active run-specific temporary upgrades.
    \item \verb|available_upgrades: Array[Upgrade]| - Stores the subset of upgrades currently eligible for purchase based on stage progression.
\end{itemize}

\subsubsection{Environment Variables}
None

\subsubsection{Assumptions}
\begin{itemize}
    \item Only one instance of the Central Hub Module exists during execution.
    \item Save data and variation configurations are initialized prior to accessing hub upgrades.
\end{itemize}
