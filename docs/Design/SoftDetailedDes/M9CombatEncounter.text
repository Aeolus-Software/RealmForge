\section{MIS of Combat Encounter M9} \label{M9-CombatEncounter}

\subsection{Module}
The combat encounter module handles the state of a combat encounter, 
such as turn order, player/enemy health, actions, and win/loss conditions. 
It communicates with the respective Combat Encounter UI for player input.  

\subsection{Uses}
\begin{itemize}
	\item Godot Engine (functions, nodes, and signals provided by the engine automatically)
	\item M8 Combat Encounter Interface Module
	\item M10 Player Character Module 
	\item M11 Enemy Character Module 
\end{itemize}

\subsection{Syntax}
\subsubsection{State Variables}
\begin{itemize}
	\item \verb|turn_state|: TurnState - The state of the current turn. 
	This is important so that the game knows what step the encounter 
	is currently on (player turn, enemy turn, or encounter completed). 
	\item \verb|encounter_state|: EncounterState - The state of the combat 
	encounter (ongoing, win, or loss). This is important to keep track of in 
	order to properly end the battle when needed.
	\item \verb|action_index| - The action queued by the player from the list of options.
\end{itemize}
