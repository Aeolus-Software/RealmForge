\section{MIS of Game World Interface (M6)} \label{M6-GameWorldInterface}
\subsection{Module}
The Game World interface handles logic for traveling and travel confirmation; it will be present options of destination and label current locations, overworld information.
Serves as a switching mechanism between the multiple sub-UI interfaces for each module such as configuration, combat, central hub etc.


\subsection{Uses}
Godot Engine - Godot Control Nodes (used specifically for UI) as well as the built-in libraries.
