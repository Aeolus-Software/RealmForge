\section{MIS of Player (M10)} \label{M10-Player}

\subsection{Module}

This module abstracts the attributes of the player character 
in the RealmForge game, and provides these details to other 
modules as needed.

\subsection{Uses}

\begin{enumerate}
	\item Godot Engine (functions, nodes, and signals provided by the engine automatically)
	\item M2 Save Data IO Module
	\item M5 Variation Configuration 
	\item M13 Central Hub Module

\end{enumerate}

\subsection{Semantics}

\subsubsection{State Variables}

\begin{itemize}
	\item health : integer
	\item max\_health : integer
	\item inventory : array of custom resources (a resource will be defined to store data related to an item in the inventory)
	\item available\_actions : array of custom resources (a resource will be 
	defined to store data related to each possible action the player character 
	can take in combat, such as its damage, speed, or other qualities).
\end{itemize}

\subsubsection{Environment Variables}

\begin{itemize}
	\item the player character's visual depiction (two-dimensional sprite) 
	displayed by the user's display device
	\item the player character's visual animations displayed by the user's 
	display device
\end{itemize}
