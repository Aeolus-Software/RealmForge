\section{MIS of Combat Encounter Interface (M8)} \label{M8-CombatEncounterInterface}

\subsection{Module}
The Combat Encounter interface handles logic for displaying the state of the current combat encounter, as well as handling player selections within an encounter. 

\subsection{Uses}
\begin{itemize}
    \item Godot Engine - Godot Control Nodes (used specifically for UI) as well as the built-in libraries.
\end{itemize}
