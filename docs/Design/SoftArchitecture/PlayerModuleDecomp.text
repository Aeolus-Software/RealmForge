\begin{description}
	\item[Secrets:]The player character in the RealmForge game's internal 
	state.
	\item[Services:]Provides the state of the player character to 
	other system modules where needed. Provides the player's displayed 
	image(s) and animation(s) to the Godot Engine for display, and provides their 
	health, game actions, and other required attributes to the Combat 
	Encounter Module \mref{mEncounter} to facilitate combat encounter game 
	scenes.
	\item[Implemented By:] RealmForge
\end{description}
