
These items are not expected to change during the capstone, so they are not treated as 
module secrets and are documented rather than encapsulated in a separate module secret:

\begin{description}

\ULC{Single-Player Gameplay}
{RealmForge is intended for single-player gameplay, where one player engages and progresses through the game.}
{The game is developed with the intention of supporting single-player gameplay. Adding multiplayer functionality would require significant changes to the game's core design and features.}

\ULC{Main Menu Functionality}
{RealmForge provides players with a main menu interface, allowing access to the game's features.}
{The main menu serves as an integral part of the game for overall navigation. While the layout and design are open to changes, the core purpose of the main menu will remain unchanged.}

\ULC{Combat Encounters}
{RealmForge includes combat encounters where the player interacts with enemy characters.}
{Combat encounters are critical to the structure and design of RealmForge. While specific combat interactions and actions may vary, the overall concept of players engaging in combat will remain unchanged.}

\ULC{Game Engine}
{RealmForge is developed using the Godot game engine.}
{The project is designed around Godot, and changing the game engine would require changes to several parts of the implementation.}

\ULC{Feature Variation System}
{RealmForge allows players to select different properties that affect their gameplay experience.}
{Feature variation is a core part of RealmForge. Although the available variations may change, the ability to configure gameplay properties is expected to remain part of the system.}

\end{description}
