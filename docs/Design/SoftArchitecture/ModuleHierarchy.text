This section provides an overview of the module design. Modules are summarized
in a hierarchy decomposed by secrets in Table \ref{TblMH}. The modules listed
below, which are leaves in the hierarchy tree, are the modules that will
actually be implemented.

\begin{description}
	\item [\refstepcounter{mnum} \mthemnum \label{mInput}:] User Input Module
	\item [\refstepcounter{mnum} \mthemnum \label{mSaveIO}:] Save Data IO Module
	\item [\refstepcounter{mnum} \mthemnum \label{mUI}:] User Interface Module
	\item [\refstepcounter{mnum} \mthemnum \label{mConfig}:] Variation 
	Configuration Module
	\item [\refstepcounter{mnum} \mthemnum \label{mWorld}:] Game World Module
	\item [\refstepcounter{mnum} \mthemnum \label{mEncounter}:] Combat 
	Encounter Module
	\item [\refstepcounter{mnum} \mthemnum \label{mPlayer}:] Player Character 
	Module
	\item [\refstepcounter{mnum} \mthemnum \label{mEnemy}:] Enemy Character 
	Module
	\item [\refstepcounter{mnum} \mthemnum \label{mHub}:] Central Hub Module
	\item [\refstepcounter{mnum} \mthemnum \label{mSaveStore}:] Save Data 
	Storage Module
\end{description}
