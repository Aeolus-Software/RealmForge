The following communication channels will be used for various team discussions:
\begin{itemize}
	\item \textbf{Microsoft Teams:} A Microsoft Teams group chat will be used 
	as the central communication channel for the RealmForge development team. 
	Project decisions and meeting planning will be discussed in this chat, and 
	some team meetings will be held virtually via an audio call in the chat.
	\item \textbf{GitHub Issues:} Issues will be used to track work tasks 
	required for each project deliverable, and discussion related to each 
	issue's relevant work may be held in comments posted on the issue. The 
	format and templates used for GitHub issues are provided in section 7's 
	Workflow Plan.
\end{itemize}
