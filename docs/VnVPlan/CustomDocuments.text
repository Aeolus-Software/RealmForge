The Custom Documents the project will involve are a Feature Oriented Domain Analysis Report and a Usability Report.
\\
\\
\noindent 
A feature oriented domain analysis is an analysis showing the similarities and differences for a family of software products. It identifies common requirements and variabilities between members of a family of products, with variation parameters for each variability. Tables and/or diagrams of features can be used to display this.
\\
\\
\noindent
A usability report is a systematic, rigorous and quantified report summarizing the results of usability testing plans. These results include metrics collected from game sessions, and user feedback about game design, issues/bugs, and user experience recommendations.
