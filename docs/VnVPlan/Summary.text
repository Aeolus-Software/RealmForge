The software that will be tested is the RealmForge software, a game in the roguelite genre (features randomized runs with most progress resetting on defeat with some permanent upgrades) focused on expanding a central hub to aid in combat encounters. The system consists of many components including the Configuration Menu (allows tester to vary certain system variables to alter gameplay), Physical controls (handling input from physical devices like keyboards or game controllers), the Combat System (handling enemy encounters, attacks, and combat outcomes), a Central Hub (a hub to produce resources to fuel combat with temporary and permanent upgrades), a Map (allows user to travel to destinations and encounters) and a User Interface (menus and HUD elements).
