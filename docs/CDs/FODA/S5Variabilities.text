\variable{Player Health}
{player\_health}
{$\mathbb{R}^{+}$}
{50\dots200}
{The player contains attributes such as health (and variety of components) that can be customized later on when designing the game. Health is the life condition which determines whether the game continues or not depending on if the values reach zero. The variation parameter ranges between 50 to 200 which is subject to change and could be much higher. This is a basic setting to test how well the player can last with different starting amounts.}     
{runtime} 

\variable{Enemy Health}
{enemy\_health}
{$\mathbb{R}^{+}$}
{60\dots150}
{Similar to the player variation, the enemy contains health. This is another difficulty setting to test how well a player does against an enemy with high or low amounts of health.}     
{runtime} 

\variable{Enemy Type}
{enemy\_types}
{set of string}
{Weak, Normal, Strong, ...`adjectives'}
{The type of the enemy is meant to convey broad details of the opponent such that the player knows how to categorize and deal with certain enemies.}
{compile-time}

\variable{Attack Type}
{attack\_types}
{set of string}
{Attack, Block, Item,... `action phrases'}
{These are the actions that allow the player and enemy to interact and convey progress in combat. They will also appear on the UI options for the player combat screen.
Each action will have a unique logic to how it effects the target opposition.}
{compile-time}

\variable{Resource Distribution}
{resource\_amount}
{$\mathbb{R}^{+}$}
{0\dots200}
{These are the possible rewards amounts that can take place when completing a combat encounter. These values can once again be tuned in the configuration menu for pacing, and difficulty.}
{runtime}

\variable{Purchase Options}
{Dictionary:  $string \mapsto string \cap integer \cap Array[Str,Int] \cap Bool$}
{item1 = \{`purchase\_name': "vigor", `cost': 100/150/200, `description': `Strength of will', `is\_purchased': true\}}
{These are the requirements and description of a purchasable. The name of the purchasable and description will hint at the effect of the item. The cost is the requirement needed to obtain the purchasable. Once purchased, the flag `is\_purchased’ will denote true and the purchasable can no longer be purchased again.}
{compile-time}

\variable{User Interface}
{Dictionary: $string \mapsto integer \cap string$}
{button1 = {`x': 10, `y': 20, `width': 200, `height': 500, `text' = `buy'}}
{The UI elements can vary in size, shape, and positioning. These values can be tuned to improve the look and feel of the game. A clean UI is something that will prevent confusion and frustration for the user. The look and feel for a game UI is different based on the preference of the user, so different UI configurations are available on the configuration menu.}
{compile, runtime (configuration)}
