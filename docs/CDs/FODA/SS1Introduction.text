This Feature-Oriented Domain Analysis (FODA) document defines the baseline features and the configurable variation points for the RealmForge roguelite game. Commonalities is the section which details the common features which must remain the same among all varied versions of the game. Variablities details the variation points which will create the different versions of the game and how these variation points may differ from one version to the next. Finally, Relationship between Commonalities and Variabilities describes dependencies, constraints, and compatability rules between the fixed features and variation points.
