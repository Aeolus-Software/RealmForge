The project can be broken down into the following core components:

\begin{itemize}
	\item \textbf{Physical Controls}: This component handles input between the \hyperlink{player}{player} and the game. This can be achieved through a computer keyboard or a standard game controller. The input enabled by this component allows player interaction with other components and is typically constrained/enforced through the \hyperlink{UI}{UI}.

	\item \textbf{User Interface (\hyperlink{UI}{UI})}: This component allows the player to interact with the game (using their preferred interaction method). This is shown through various menus, buttons and other visual prompts and ensures the game is intuitive to navigate while constraining the player to certain intended methods of interaction.

	\item \textbf{Game Settings}: This component contains various selections that allow the player to change aspects of the game. This allows the player to customize how they interact with the game in ways such as gameplay, audio, and visual changes.

	\item \textbf{Combat System}: This component contains an integral piece of the system, as selected using the map system. This is the main way the player will interact with the game. This includes everything needed for a combat encounter, such as player and enemy properties, possible actions, current game state and the condition(s) needed to win a fight.

	\item \textbf{Map System}: This component contains the main means of traversal for the player, bringing together the various encounters into a linear progression (with some branching and converging) and giving a sense of progression and a goal to work towards. 

	\item \textbf{Central Hub}: This component contains the hub area for the game which holds most resource management in the game. This is returned to between runs for some permanent progression, and interacted with during a run to manage run resources.

\end{itemize}
