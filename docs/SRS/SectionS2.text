\subsection*{\textbf{Physical Controls:}}
\textcolor{purple}{\textbf{Function Requirements:}}

\requirement{SFR}
{The controller button-bindings should have a keyboard and mouse equivalent.}
{The user must have full access to all functionality of the game with either a controller or keyboard and mouse. There should not
be any discrepancy or gap with using one over the other.}
{The direction pad of the controller should be handled exactly like the keyboard and mouse direction keys, left, right, up, down.}
{\ref{controller-constraint}}
{controller-equivalence}

\noindent
\textcolor{teal}{\textbf{Non-Function Requirements:}} 

\requirement{SNFR}
{The inputs for the used controller should have almost immediately response time for the game}
{Any major input delays will make the make feel sluggest or slow to repond to any \hyperlink{player}{player} feedback.}
{The game response time in handling the players input is less than a second.}
{\ref{controller-constraint}}
{controller-nolag}

\subsection*{\textbf{Combat System:}}
\textcolor{purple}{\textbf{Function Requirements:}} %**************** SUBTITLE FUNCTIONAL ****************

\requirement{SFR}
{The game shall show the player and enemy and their respective health bars during the combat screen.}
{Needed to indicate the player the urgency of the situation during combat.}
{The game displays the in-game player sprite and enemy sprite and two green health bars right below respective sprites.}
{N/A}
{combat-display}

\requirement{SFR}
{The game shall show an indication of success if the enemy's health goes to zero or failure if the player's health goes to zero.}
{This is needed in order to know when the combat has concluded.}
{The game displays the in-game player sprite and enemy sprite and two green health bars right below respective sprites.}
{N/A}
{combat-ends}

\requirement{SFR}
{The game shall show an attack visual whenever the player presses an attack option. Similar, the game shall display a visual for the enemy's opposing attack.}
{The combat needs to be telegraphed some way or manner.}
{The game displays the in-game characters sword swinging up and down to indicate the attack.}
{N/A}
{combat-attack}

\noindent

\requirement{SNFR}
{Combat should be exciting and very engaging to the player.}
{This is a key moment of the game. If the player is not satisfied or feel exhilerated, then the player will no long feel the urge to continue the game.}
{The game has a very fun and addicting combat that keeps the player from turning if off.}

{controller-exciting}
