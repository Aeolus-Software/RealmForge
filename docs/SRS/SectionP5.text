\newline
The RealmForge software will be run, developed, and tested using hardware that supports Windows 10/11 \hyperlink{OS}{OS}. Other OS's such as Apple's or other platforms
will be considered after the initial development showcase. Inputs are handled either with a standard keyboard and mouse or
with a connected controller using standard button layout (analog sticks, d-pads, shoulder and 4-buttons layout). The controller
should be compatible with any Windows OS, similarly to the mouse and keyboard. The game output will be displayed using any standard monitor
connected to the computer hardware.

\noindent
\newline
The system will be built using the Godot game engine, including using Godot's own coding language, GDScript.
Godot is an open-source application and has an easy learning curve to implement features, which is a main concern regarding this project.
The easier the team can fully pick up the engine, the faster and cleaner it is to create a working concept.
Each team member will choose their own \hyperlink{IDE}{IDE}. \hyperlink{GDUnit4}{GDUnit4} and \hyperlink{GDLint}{GDLint} and other external third-party modules will be used for \hyperlink{CI/CD}{CI/CD}
as a safeguard for good coding practices and coverage. The project will use GitHub's version control and cloud storage 
for the source code and documents. The GDLint and GdUnit4 unit tests and linting will be implemented using GitHub Actions available
on the GitHub website; this is so that errors and bugs will be caught and reiterated early on. \hyperlink{latex}{LaTeX} will be used for writing
important documents such as Hazard Analysis, Development, etc. Issues about the project will be raised on the GitHub website
and written/handled with its own built-in issue tracker. Other important project management tasks will be written using GitHub  Project's
Kanban board for organization and easy tracking.
