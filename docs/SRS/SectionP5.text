\newline
The application will be run, developed and tested using hardware that supports the Window's \hyperlink{OS}{OS}. Other OS's such as Apple's or other platforms
will be considered after the initial development showcase. Inputs are handled either with a standard keyboard and mouse or
with a connected controller using standard button layout (analog sticks, d-pads, shoulder and 4-buttons layout). The controller
should be compatible with any Windows OS, similarly to the mouse and keyboard. No unique gaming peripheral is necessary.
No enhanced audio peripheral is necessary. The game output will be displayed using any standard monitor connected to the computer hardware.

\noindent
\newline
The system will be built using the Godot game engine including using Godot's own coding language, GDScript. The \hyperlink{IDE}{IDE} will be up to
each individual team member's preference. \hyperlink{GDUnit4}{GDUnit4} and \hyperlink{GDLint}{GDLint} and other external third-party modules will be used for \hyperlink{CI/CD}{CI/CD}
as a safeguard for good coding practices and coverage. The project will use Github's version control and cloud storage 
for the source code and documents. The GDLint and GdUnit4 unit tests and linting will be implemented using using Github Actions available
in the Github website; this is so that errors and bugs will be caught and reiterated early on. \hyperlink{latex}{LaTex} will be used for writing
important documents such Hazard Analysis, Development etc. Issues pertaining to the project will be raised on the Github website
and written/handled with its own built-in issue tracker. Other important project management tasks will be written using Github Project's
Kanban board for organization and easy tracking. Microsoft teams is the main technology platform that is used for communication such as
in group chats and voice-calls.
