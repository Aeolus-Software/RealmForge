The tasks required to be completed to develop RealmForge (and its feature 
variation capabilities) will be managed using an iterative and incremental 
approach. Within each milestone (in this context the milestones associated with 
source code development), team members will divide the work to be done 
into suitable issues, viewable in RealmForge's 
\href{https://github.com/orgs/Aeolus-Software/projects/2}{{GitHub Project}}. 
The issues will be coordinated using a Kanban method, tracking their progress 
and review status.
The software features associated with these issues will be regularly planned, 
developed, reviewed, tested, and deployed using a feature branch workflow, 
contributing towards each set milestone.

of 
each deliverable. Milestones that purely involve documentation development are
