\textbf{SSR-001}: Save data is associated with specific game profiles saved on the device.

\textbf{SSR-002}: Ensure all playtester information and evaluation metrics are securely stored and restricted from unauthorized access.T

\textbf{SSR-003}: Save files and player data will be validated upon launch to detect and reject malformed data.

\textbf{SSR-004}: Unsaved progress or session data will be stored locally on the user's device if an unexpected exception or failure occurs.

\textbf{SSR-005}: The application shall handle unexpected runtime exceptions gracefully to prevent permanent data corruption to local save files or destabilization of the host operating system.

\textbf{SSR-006}: The application shall display a warning about flashing lights and not have excessive flashing lights during gameplay.

\textbf{SSR-007}: Game data shall be consistently saved and verify data is not lost throughout gameplay.
