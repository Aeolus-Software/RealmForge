\textbf{SSR-001}: Save data is associated with specific game profiles saved on the device.

\textbf{SSR-002}: Ensure all playtester information and evaluation metrics are securely stored and restricted from unauthorized access.T

\textbf{SSR-003}: Save files and player data will be validated upon launch to detect and reject malformed data.
